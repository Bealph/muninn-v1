# Glossaire de la veille

Termes techniques des fiches et des synthèses, définis pour un lecteur non spécialiste.

| Terme                   | Définition                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Journaux                | relevés que les applications écrivent au fil de leur fonctionnement, pour savoir après coup ce qui s'est passé.                                        |
| Container Apps          | service d'Azure qui fait tourner les applications de Muninn.                                                                                           |
| Log Analytics           | Service d'Azure où les journaux sont stockés et interrogés ; la « destination Log Analytics » de Container Apps est l'ancienne façon de les y envoyer. |
| Azure Monitor           | la destination que Microsoft recommande désormais pour ces mêmes journaux.                                                                             |
| Option héritée          | réglage encore disponible et en service, mais que l'éditeur ne recommande plus.                                                                        |
| Alerte AL-04            | règle de surveillance de Muninn qui lit les journaux de Container Apps pour déclencher une alerte.                                                     |
| Classeur d'exploitation | tableau de bord du projet construit à partir des mêmes journaux.                                                                                       |
| SDK                     | boîte à outils logicielle qu'un service fournit pour que d'autres programmes puissent l'utiliser.                                                      |
| Préversion              | version mise à disposition pour essai avant d'être déclarée stable.                                                                                    |
| Flux                    | fil de nouvelles qu'un site publie et qu'un programme lit automatiquement ; la veille en suit 11.                                                      |
| Dépôt                   | espace sur GitHub où est rangé le code du projet ; il peut être privé ou public.                                                                       |
| Norme harmonisée        | norme technique européenne dont le respect fait présumer qu'une exigence du règlement est remplie.                                                     |
